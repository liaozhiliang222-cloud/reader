# 编码测试样本

所有文字为本项目自编的合成测试内容，不含外部书籍或用户数据。`.bin` 是真实编码字节；对应 `.expected.txt` 是 UTF-8 解码预期，保留 CRLF，不按显示内容生成测试预期。

执行 `python src/parsers/txt/fixtures/generate.py` 可重建样本，同时将 TXT 复制到已被 Git 忽略的 test-books/。Python 仅用于生成静态样本，运行应用及单测都不需要 Python，也不新增 npm 依赖。

GB18030 样本包含需四字节编码的扩展汉字。UTF-16 覆盖双端序、有无 BOM。Big5 样本专门展示歧义：其字节也能通过 GB18030 严格解码，按计划返回 GB18030，不能宣称自动 Big5 识别正确。后续 M2-06 手动编码选择用于这种情况。

本目录只完成 P-03 的编码素材部分；千章性能文件、无章节文件及 EPUB 素材尚未生成。合成 GBK 样本验证不替代真实网文文件验收。
